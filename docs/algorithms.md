# Uniform small-width implementations

The generic transformation and elimination loops have appreciable fixed overhead at very small widths. `src/rank/small_rank.hpp` packs up to sixteen m-bit coefficient vectors into four-bit lanes of one 64-bit word. XOR, shifts and masks perform the usual Moebius transform. Each inserted coefficient moves between the 67 linear subspaces of F2^4; the table is generated algebraically at compile time, not learned from S-boxes. It implements exactly the same row-span rank used in the general method. Zero and constant components retain degree zero.

A swap XORs `(supersets[p] ^ supersets[q]) * (S[p] ^ S[q])` into the packed ANF. Each selected nibble has value one before multiplication, so the difference is broadcast without carries. Entries outside the n-bit domain are ignored. Static evaluation rebuilds the packed ANF from the current truth table each time. Minimum-degree evaluation transforms the prepared packed truth table afresh on every call; optional coefficient-vector enumeration still uses the general elimination path.

The dimension condition n,m <= 4 is fixed for every input. Arbitrary, rectangular and nonbijective maps are supported. At n=5,m<=5, the minimum-degree executable additionally uses `src/rank/small_min5.hpp`: 32 output vectors occupy eight-bit lanes in four words. A five-stage Moebius transform is followed by rank transitions over all 374 subspaces of F2^5. This table is also generated algebraically, with no instance-specific entries. Its shared readonly table occupies 25,812 bytes. The build flag `COAM_SMALL_MINIMUM_5` enables it only in the minimum/maximum and corresponding verification executables. The other widths use the general algorithms. The readonly transition, rank and superset table is shared by all instances; `sizeof(small_rank::Tables)` is 1,416 bytes and is not included in per-instance allocated-state figures. Whole-process memory includes the binary and its readonly data.


The `src/rank/search_constraints.hpp` implementation uses Menyachikhin's transposition updates for the Walsh and difference distribution tables. `make check` validates the degree calculations, optional minimum-degree vectors, coefficient updates, consecutive swaps, rollback and all search candidates.
